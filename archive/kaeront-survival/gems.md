# 💎 Гемы (Gems)

**Гемы** — это особая ценная валюта сервера, необходимая для покупки глобальных усилений и участия в экономике.

### Способ добычи
* Гемы можно получить при добыче любых руд.
* **Обязательное условие:** Руда должна быть добыта инструментом с зачарованием **«Шёлковое касание»** (Silk Touch).
* **Важное ограничение:** Инструмент должен быть предназначен для успешной добычи данной руды. Если сломать алмазную руду деревянной киркой, гемы **не выпадут**, а руда будет уничтожена без выгоды.

### Команды гемов
* `/gems` — проверить баланс своих гемов.
* `/gems <игрок>` — узнать количество гемов у указанного игрока.
* `/gems-pay <игрок> <сумма>` — перевести указанное количество гемов другому игроку.
